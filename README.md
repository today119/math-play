# 🐾 동물 친구 수학 놀이터

아이가 스스로 수준을 골라 수학 놀이를 하고, 동물 친구를 키우며 진화시키는 웹앱.

- 수준 4가지: 🐣 숫자 쓰기(4~5세) · 🐥 더하기·빼기(6~7세) · 🐔 구구단(8~9세) · 🦅 빠른 계산(10세~)
- 단계를 깨면 🍖 먹이(동물 성장) + 🎟 게임 티켓(짝 맞추기 · 블록 쌓기 · 카트 달리기)
- 하루 놀이 시간 제한, 부모 화면(비밀번호)
- 영상·광고·바깥 링크 없음. 기록은 그 기기에만 저장(localStorage). 설치 없이 홈 화면에 추가해서 사용.
